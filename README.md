# Failed payment notice

How Chekin warns a customer for 14 days when their subscription payment fails, before the account is suspended: a dashboard banner, a pop-up, a payment screen and 8 emails.

**Live page:** https://dclemares.github.io/payment-failed-notice/

- `index.html` is a single static page; click any screenshot to see it full size.
- `img/` holds the prototype screenshots and email renders.

Amounts, names and card details in the screenshots are sample data.
